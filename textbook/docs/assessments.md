# Course Assessments

---

## Assessment 1: ROS 2 Package Development

**Objective:** Build a ROS 2 package demonstrating mastery of nodes, topics, services, and launch files.

### Requirements
- Create a minimum of 3 interconnected nodes
- Use at least 1 custom message type
- Include a launch file that starts all nodes with parameters
- Demonstrate pub/sub AND service communication patterns
- Include a README with setup instructions

### Deliverables
- Git repository with source code
- Screen recording of nodes running and communicating
- Brief writeup (1–2 pages) explaining your architecture

---

## Assessment 2: Gazebo Simulation

**Objective:** Create a simulated environment with a robot that responds to commands.

### Requirements
- Custom Gazebo world with at least 5 objects
- Robot spawned from URDF with working joints
- Simulated camera publishing images to a ROS 2 topic
- Basic teleoperation (keyboard or programmatic control)
- Physics interactions (pushing objects, gravity)

---

## Assessment 3: Isaac Perception Pipeline

**Objective:** Build an AI perception pipeline using Isaac ROS or standard ROS 2 vision packages.

### Requirements
- Object detection running on camera feed (real or simulated)
- SLAM or odometry providing robot localization
- Point cloud or depth-based spatial reasoning
- Visualization in RViz showing detections and map
